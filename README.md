## Описание проекта
«Карманный щит» — это обучающая консольная игра-симулятор смартфона по теме смишинга и QRishing. Игрок получает SMS, push-уведомления, сообщения в мессенджерах и сталкивается с QR-кодами. Задача игрока — распознать мошеннические сообщения и выбрать безопасный вариант действий. Игра помогает сформировать практические навыки цифровой безопасности.
